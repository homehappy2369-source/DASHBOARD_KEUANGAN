Data & penyimpanan

Penyimpanan browser lokal

Data tersimpan di browser/perangkat ini. Belum tersambung ke server MySQL.

Hapus seluruh data tidak dapat dibatalkan. Unduh cadangan terlebih dahulu jika perlu.

Persiapan integrasi aaPanel + MySQL

File HTML, CSS, dan JavaScript ini adalah antarmuka yang dapat diuji. Browser tidak boleh terhubung langsung ke MySQL dengan kredensial database. Untuk data permanen dan multi-perangkat, perlu backend API (misalnya PHP) yang melakukan autentikasi, validasi, dan query ke MySQL.
